# macOS 命令行练习笔记（2026-10-07）

> 练习环境：Mac 终端（zsh），练习目录 `~/practice`

---

## 一、终端基础知识

### 提示符（prompt）
终端每行开头的 `(base) hj1993@主机名 目录 %` 是**提示符**，不是命令的一部分。

### ⚠️ 重要坑：`$` 不要输入
教程中的 `$ whoami`：
- `$` 只是示意"这里是输入位置"
- **只输入 `$` 后面的内容**，否则报错 `command not found: $`

### 提示符各段含义
| 部分 | 含义 |
|------|------|
| `(base)` | Anaconda 环境（可忽略） |
| `hj1993` | 当前用户名 |
| `主机名` | Mac 的名字 |
| `practice` | 当前所在目录 |
| `%` | zsh 提示符结尾 |

### 常用符号
| 符号 | 名称 | 作用 |
|------|------|------|
| `&` | 后台运行符 | 命令放后台执行，终端立刻可用 |
| `|` | 管道 | 把左边命令的输出，作为右边命令的输入 |

## 二、七个命令详解

### 1. chmod — 修改权限
| 项目 | 内容 |
|------|------|
| 全称 | change mode（改变权限模式） |
| 中文 | 修改文件/目录的访问权限 |
| 作用 | 控制读(r=4)、写(w=2)、执行(x=1)权限 |

**常用选项：**
| 选项 | 含义 | 作用 |
|------|------|------|
| `-R` | recursive 递归 | 递归修改目录及其全部内容 |
| `+x` | 加执行权限 | 如 `chmod +x script.sh` |
| `u/g/o/a` | 所有者/组/其他人/所有人 | 指定权限对象 |

**数字权限：** 755 = 所有者 rwx(7)，组和其他人 r-x(5)

---

### 2. ps — 查看进程
| 项目 | 内容 |
|------|------|
| 全称 | process status（进程状态） |
| 中文 | 查看正在运行的进程 |
| 作用 | 显示进程的 PID、CPU、内存、命令等信息 |

**常用选项（BSD 风格可不带 `-`）：**
| 选项 | 全称 | 作用 |
|------|------|------|
| `a` | all users | 所有用户的进程 |
| `u` | user-oriented | 详细格式（含 CPU%、内存%） |
| `x` | no tty | 包含无终端的后台进程 |
| `-A` / `-e` | all | 所有进程 |
| `-l` | long | 长格式详情 |

**经典组合：** `ps aux` = 全系统进程详细信息
**配合管道筛选：** `ps aux | grep sleep` 从进程列表中找出含 "sleep" 的行

---

### 3. sleep — 休眠（练习用）
| 项目 | 内容 |
|------|------|
| 全称 | sleep（睡眠） |
| 中文 | 休眠命令 |
| 作用 | 进程什么都不做，睡 N 秒后自动退出 |
| 用法 | `sleep 300 &` 后台睡 300 秒，制造练习进程 |

---

### 4. kill — 杀进程
| 项目 | 内容 |
|------|------|
| 全称 | kill（杀死/终止） |
| 中文 | 向进程发送信号，默认终止进程 |
| 作用 | 结束进程（本质是发信号，不是删除） |

**常用信号：**
| 写法 | 信号名 | 作用 |
|------|--------|------|
| `kill PID` | SIGTERM (15) | 礼貌请求终止（默认），进程可清理后退出 |
| `kill -9 PID` | SIGKILL | 强制杀死，无法忽略、无法清理，**慎用** |
| `kill -1 PID` | SIGHUP | 让进程重载配置文件 |
| `kill -l` | — | 列出所有可用信号 |

**相关命令：**
- `jobs` 查看后台任务（作业号）
- `kill %1` 用作业号杀（加 `%`）
- `fg %1` 把后台任务调回前台

---

### 5. ping — 网络连通测试
| 项目 | 内容 |
|------|------|
| 全称 | ping（声纳的"乒"声） |
| 中文 | 网络连通性测试 |
| 作用 | 发 ICMP 包测试目标是否可达、延迟多少 |

**常用选项：**
| 选项 | 全称 | 作用 |
|------|------|------|
| `-c 次数` | count | 发 N 次后自动停止（**macOS 必备**） |
| `-i 秒` | interval | 设置间隔时间 |
| `-s 大小` | size | 设置数据包大小 |

**用法：** `ping -c 4 baidu.com`（停止按 Ctrl+C）

---

### 6. ssh — 安全远程登录
| 项目 | 内容 |
|------|------|
| 全称 | Secure Shell（安全外壳协议） |
| 中文 | 加密远程登录 |
| 作用 | 远程登录另一台机器并执行命令 |

**常用选项：**
| 选项 | 全称 | 作用 |
|------|------|------|
| `-p 端口` | port | 指定端口（默认 22，**小写 p**） |
| `-i 密钥` | identity | 使用指定私钥登录 |
| `-l 用户` | login | 指定用户名 |
| `-v` | verbose | 调试模式，排错用 |

**语法：** `ssh 用户名@主机IP`

---

### 7. scp — 安全远程复制
| 项目 | 内容 |
|------|------|
| 全称 | Secure Copy（安全复制协议） |
| 中文 | 通过 SSH 加密通道远程拷文件 |
| 作用 | 本地与远程之间复制文件/目录 |

**常用选项：**
| 选项 | 全称 | 作用 |
|------|------|------|
| `-r` | recursive | 递归复制目录（**小写 r**） |
| `-P 端口` | port | 指定端口（**大写 P**，与 ssh 相反！**） |
| `-i 密钥` | identity | 指定私钥 |
| `-p` | preserve | 保留修改时间和权限 |
| `-C` | compress | 传输时压缩 |

**语法：**
```bash
scp 本地文件 用户@主机:~/远程路径    # 上传
scp 用户@主机:~/远程文件 本地路径    # 下载
```

---

### 8. ar — 归档工具
| 项目 | 内容 |
|------|------|
| 全称 | archive（归档） |
| 中文 | 静态库打包/归档命令 |
| 作用 | 将多个文件打包成 `.a` 归档（C/C++ 静态库） |

**常用选项：**
| 选项 | 全称 | 作用 |
|------|------|------|
| `-c` | create | 创建归档 |
| `-r` | replace | 插入/替换归档内文件 |
| `-t` | table | 列出归档内容 |
| `-x` | extract | 解压归档 |
| `-v` | verbose | 显示详情 |

> ⚠️ macOS 自带的是 BSD 版 ar，功能弱于 Linux GNU 版；如需完整版 `brew install binutils`

## 三、实操练习记录

### 练习 1：chmod
```bash
mkdir ~/practice && cd ~/practice
echo 'echo "我运行了!"' > hello.sh
chmod +x hello.sh       # 加执行权限
ls -l hello.sh          # 对比权限变化
./hello.sh              # 执行成功
chmod 000 hello.sh      # 剥夺所有权限 → Permission denied
chmod 755 hello.sh      # 恢复
```

### 练习 2：ps + kill
```bash
sleep 300 &             # 后台进程，记下输出的 PID
ps aux | grep sleep     # 找到 PID（第 2 列；注意排除 grep 自身那行）
kill PID                # 礼貌终止
kill -9 PID             # 强制终止
kill -l                 # 列出所有信号
jobs / fg %1 / kill %1  # 作业号相关操作
```

### 练习 3：ping
```bash
ping -c 4 baidu.com
ping -c 2 -s 1000 8.8.8.8
ping -c 3 -i 2 114.114.114.114
```

### 练习 4：ar
```bash
echo "内容1" > a.txt
echo "内容2" > b.txt
ar -crv mylib.a a.txt b.txt   # 创建打包
ar -t mylib.a                 # 查看内容
ar -xv mylib.a                # 解压
```

### 练习 5：ssh + scp（本机连本机）
```bash
# 1. 开启远程登录：系统设置 → 通用 → 共享 → 远程登录
whoami                        # 查用户名（本次为 hj1993）
ipconfig getifaddr en0        # 查 Wi-Fi 网卡 IP（本次为 192.168.8.168）

# 2. ssh 连接
ssh hj1993@192.168.8.168

# 3. 第一次连接的提示 → 输入 yes（完整单词，不能只输 y）
# 4. 输 Mac 开机密码（盲打，屏幕无显示是正常的）
# 5. exit 退出

# 6. scp 上传 + 远程验证
scp remote.txt hj1993@192.168.8.168:~/
ssh hj1993@192.168.8.168 'cat ~/remote.txt'
```

## 四、踩坑记录 ⭐

| 坑 | 现象 | 解决 |
|----|------|------|
| 把 `$` 当命令输入 | `zsh: command not found: $` | `$` 是提示符示意，只输后面的内容 |
| ssh 首连确认 | 提示 Are you sure... | 输完整 `yes`，不能只输 y |
| ssh 密码不可见 | 输密码时屏幕毫无反应 | 正常现象，盲打完直接回车 |
| grep 自己也被列出 | ps 结果有两行含 sleep | 命令列显示 `grep sleep` 的是 grep 自己，忽略 |
| scp 端口参数 | 报错或连不上 | scp 用大写 `-P`，ssh 用小写 `-p`，别记混 |
| ping 停不下来 | 一直 ping 不退出 | macOS 必须加 `-c 次数`，或按 Ctrl+C |
